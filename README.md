# 墨香词韵 — 张明江诗词散文集 📖

欢迎来到《张明江诗词集》的官方开源仓库！这里收录了我的原创诗词、散文及各类文学创作。

🌐 **在线阅读**：[点击访问 https://redrosa966.github.io/mingjiang-poems/](https://redrosa966.github.io/mingjiang-poems/)

---

## 🌟 项目特色

- **内容丰富**：涵盖政经抒怀、乡情感怀、绝句律诗等多个主题分类。
- **响应式阅读体验**：支持桌面端与移动端流畅阅读，界面典雅简洁。
- **数据与内容分离**：后台采用数据库结构化管理，前台动态渲染呈现。

---

## 🛠️ 技术架构与设计

这个项目不仅是一个文学作品库，也是一次“数据库与现代 Web 前端集成”的跨界尝试：

1. **后台存储**：使用 Microsoft Access 进行诗词元数据的分类、目录索引与本地架构管理。
2. **数据同步**：借助 Access VBA 自动化脚本将诗词导出为 JSON 数据，并自动推送同步。
3. **前端呈现**：基于 GitHub Pages 构建轻量级、高可用的 Web 展示与阅读界面。
